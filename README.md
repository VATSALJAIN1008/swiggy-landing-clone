# Swiggy Landing Page Clone

A static, responsive replica of the Swiggy homepage built with plain HTML5 and CSS3. The project demonstrates the use of semantic markup, Flexbox, CSS Grid, and media queries to create a layout that works on desktop, tablet, and mobile screens.

## How to View
1. Open the folder in a file explorer.
2. Double‑click `index.html` (or run `start index.html` from PowerShell).
3. The page will load locally – no server or JavaScript is required.

## Features Implemented
- Orange navigation bar with Swiggy logo.
- Hero section with a delivery‑focused image.
- Service cards for Food Delivery, Instamart, and Dineout.
- Food categories (Pizza, Burger, Biryani, Cake, North Indian, South Indian).
- Instamart categories (Fresh Vegetables, Fresh Fruits, Dairy, Munchies, Cold Drinks, Personal Care).
- Responsive layout using Flexbox and CSS Grid; media queries for desktop, tablet, and mobile.

## Missing / Optional Polish
- Exact typography (font‑family, weight) to match the live Swiggy site.
- Fine‑tuned spacing and alignment for pixel‑perfect visual parity.
- Additional interactive elements (e.g., hover effects) are omitted as JavaScript is not required.
